# 大袋東小 ニュース検索（試作）

学校公式サイトの公開ニュースを定期取得し、個人用の静的サイトで全文検索・画像一覧表示するためのスタータープロジェクトです。

## できること
- 記事タイトル・本文・日付・カテゴリの検索
- 記事一覧から公式サイトの元記事を開く
- 記事内画像の一覧表示（画像ファイルは保存せず、公式サイトから直接読み込み）
- GitHub Actions による毎日の自動取得と GitHub Pages への公開

## 大事な注意
- これは**未検証の試作**です。学校サイトの表示仕様が変わると取得処理を調整する必要があります。
- 学校サイトの利用条件・robots.txt・アクセス頻度を確認し、許可されていない取得はしないでください。学校サイトへ大量アクセスしないよう、1日1回の実行を基本にしています。
- 児童の写真・記事を第三者向けに再配布・公開する権利があるとは限りません。**公開前に学校・権利者の利用条件を確認してください**。このプロジェクトは画像ファイルを複製しませんが、公開サイトに画像リンクを並べることも、写真をより見つけやすくする行為です。許可を確認できない場合は、`app.js` の画像表示を無効化するか、サイトを公開しないでください。
- GitHub Pages は通常、公開サイトです。個人利用であっても、URLを知る人がアクセスできる可能性があります。
- このサイトは学校公式サイトではなく、学校との提携・承認を示すものではありません。

## 公開手順（GitHub Pages）
1. GitHub で新しいリポジトリを作成し、このフォルダー内のファイルをアップロードします。
2. リポジトリの **Settings → Actions → General → Workflow permissions** で、必要に応じてワークフローの書き込み権限を許可します。
3. **Settings → Pages** で公開元を **GitHub Actions** に設定します。
4. **Actions** タブから `Update school index and publish` を手動実行します。
5. 実行ログで `記事リンク候補` と `保存しました` の件数を確認し、Pages の公開URLを開きます。
6. 初回の取得が失敗した場合は、サイトのHTMLや追加読み込みの仕組みを確認して `scripts/crawl.py` のセレクターを調整します。

## 取得の仕組み
Playwright で一覧ページを開き、「次の10件を表示」を順に押して記事リンクを収集し、各記事を開いて本文と画像URLを抽出します。取得した結果は `data/articles.json` に保存され、フロントエンドがこのJSONを検索します。

## ローカルで試す
Python 3.12 以上を用意し、ターミナルでこのフォルダーに移動して実行します。

```bash
pip install -r requirements.txt
python -m playwright install chromium
python scripts/crawl.py
python -m http.server 8000
```

その後 `http://localhost:8000` を開きます。ブラウザーで `index.html` を直接開くとJSON読み込みが制限されるため、簡易サーバー経由で確認してください。

## よくある問題
- **0件取得**：サイトが自動アクセスを拒否している、Cookie/JavaScriptが必要、ボタン名が変わった、または一覧URLが変わった可能性があります。何度も繰り返さずログを確認してください。
- **本文がメニューばかり**：学校サイト側の本文コンテナーを調べ、`scripts/crawl.py` の `selectors` を実際のHTMLに合わせます。
- **画像が表示されない**：元サイトが外部埋め込みを制限している、画像URLにセッションが必要、または画像の公開条件が異なる可能性があります。
